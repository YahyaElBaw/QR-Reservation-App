0. DESIGN IDEA
---------------------------------------------------------------------
"Medina Blue" - inspired by Tunisian whitewashed walls and blue doors
(Sidi Bou Said). Cool white surfaces, one confident blue, saffron used
only to draw the eye to the single most important action/number.
Calm, fast, readable in a busy room, one-handed on a phone.

Principles
  1. One primary action per screen (blue). Saffron = highlight only.
  2. Big touch targets (min 48px), thumb-reachable actions at the bottom.
  3. Status is always color + icon + text (never color alone).
  4. Prices are the most legible thing on a product card.
  5. Sentence case everywhere. No ALL-CAPS labels. No decorative gradients.
  6. Tinted blue shadows, not grey. Few shadows: only cards that float.

4. SPACING, RADIUS, ELEVATION, SIZES
---------------------------------------------------------------------
  Spacing (4pt grid): 4, 8, 12, 16, 20, 24, 32, 40, 56, 72
    space-1=4 space-2=8 space-3=12 space-4=16 space-5=20
    space-6=24 space-8=32 space-10=40 space-14=56 space-18=72
  Screen padding: 16 (mobile) / 24 (tablet) / 32 (desktop)

  Radius (different on purpose - hierarchy)
    radius-sm   8    chips inside cards, small tags
    radius-md   12   buttons, inputs
    radius-lg   20   cards, product cards
    radius-xl   28   bottom sheets, modals (top corners)
    radius-full 999  badges, avatars, quantity stepper

  Elevation (blue-tinted)
    shadow-1  0 1px 2px rgba(11,47,87,0.08)
    shadow-2  0 6px 18px rgba(11,47,87,0.12)   floating cart bar, dropdowns
    shadow-3  0 16px 40px rgba(11,47,87,0.18)  modals
    Cards in lists: border 1px border + NO shadow.

  Sizes
    touch target min   48
    button height      48 (md)  /  56 (lg, main CTA)  /  36 (sm)
    input height       48
    icon sizes         20 (inline) / 24 (default) / 32 (feature)
    product image      1:1 ratio on cards, radius-lg
    bottom nav height  64 (+ safe area)
    max content width (web back-office) 1280 ; client web 560 centered

5. COMPONENT SPECS (build the same in Vue and Expo)
---------------------------------------------------------------------
Button
  primary   : bg primary-500, text on-primary, pressed primary-600
  secondary : bg primary-50, text primary-700, border primary-100
  ghost     : transparent, text primary-600
  danger    : bg danger-500, text white
  highlight : bg accent-500, text on-accent (ONLY for "Place order"/"Pay")
  disabled  : bg surface-alt, text text-faint
  radius-md, label body 700, loading state = spinner replaces label, keep width

Input / Select / Search
  bg surface, 1px border, radius-md, height 48, focus ring 2px primary-500
  error: border danger-500 + message below in body-sm danger-500
  label above (body-sm 500, text-muted), never placeholder-only

Product card (client)
  image 1:1 radius-lg, name h3, description body-sm 2 lines max (text-muted),
  price bottom-left (price style), "+" round button bottom-right (primary).
  Unavailable: grayscale image, no "+" button, tag "Unavailable".

Quantity stepper : pill (radius-full), "-" qty "+" , 40x40 buttons, qty tabular.
Category chips   : horizontal scroll, pill, active = primary-500 bg / white text,
                   inactive = surface-alt bg / text.
Floating cart bar: bottom, radius-lg, bg primary-700, text white,
                   left: "3 items", right: total in accent-500, shadow-2.
Status badge     : pill, icon 16 + label, colors from section 1.
Ticket line row  : name, qty x unit price, subtotal right aligned (tabular).
Total block      : label body, value display-size in accent on dark panel
                   OR primary-900 text on accent-100 panel.
Table tile (back-office): 120x96 min, big table number (h1), status badge,
                   open ticket total if any. Tap -> ticket detail.
Data table (web) : sticky header surface-alt, row hover primary-50, 56px rows.
Toast            : bottom (mobile) / top-right (web), 4s, icon + one sentence.
Empty state      : icon 32, one sentence of what is missing, one button to fix it.
Bottom sheet / modal : radius-xl top, drag handle 36x4 border-strong, overlay token.

6. ICONS & IMAGES
---------------------------------------------------------------------
  Icons : Lucide only (lucide-vue-next / lucide-react-native), stroke 1.75,
          color inherits from text token.
  Product images : Cloudinary, always request transformed URL:
          /c_fill,ar_1:1,w_600,q_auto,f_auto/   (thumb: w_200)
  Placeholder when no image: surface-alt + utensils icon text-faint.

7. MOTION
---------------------------------------------------------------------
  Only motion that answers an action:
   - add to cart: item count bumps (scale 1 -> 1.15 -> 1, 160ms)
   - sheet open/close: 220ms ease-out
   - order confirmed: check icon draws once (400ms)
  No page-load fade-ins, no hover-lift on every card.
  Honor reduced-motion (web: prefers-reduced-motion, RN: AccessibilityInfo).
  durations: fast 120ms / base 200ms / slow 320ms  easing: cubic-bezier(.2,.8,.2,1)

8. LANGUAGE, MONEY, DATES
---------------------------------------------------------------------
  UI languages: French (default), Arabic (RTL ready), English.
  Use logical properties (margin-inline-start, ps/pe) - never left/right.
  Currency: TND, 3 decimals -> "24,500 TND" (fr) / "24.500 TND" (en)
            Intl.NumberFormat(locale, {style:'currency', currency:'TND'})
  Dates: DD/MM/YYYY HH:mm, 24h, timezone Africa/Tunis.
  Voice: short, active, user words. Buttons say what happens:
    "Add to cart", "Place order", "Add to my order", "Mark as paid",
    "Close ticket". Errors say what went wrong + how to fix, no apologies.
    The same action keeps the same name in button, toast and history.

9. ACCESSIBILITY FLOOR
---------------------------------------------------------------------
  Contrast AA, visible focus ring (web), accessibilityLabel on every icon
  button (mobile), alt on images, 48px targets, text scales to 200%,
  no information by color alone.
